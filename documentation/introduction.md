# Software Engineering Practical

## Introduction

This practical assignment focuses on software development environments, modelling tools, and source-control systems.

## Tools to Be Studied

1. IBM Rational DOORS
2. Sparx Enterprise Architect
3. Eclipse
4. IntelliJ IDEA
5. NetBeans
6. Microsoft Visual Studio
7. Xcode
8. Git and GitHub

## Learning Objectives

- Understand software development tools.
- Learn how to manage software repositories.
- Understand commits, branches and merges.
- Learn collaborative software development.
- Understand issue tracking and continuous integration.
